# WorkSpace Ultra

Персональная Kanban-доска для планирования задач. Приложение работает в браузере и сохраняет доску и настройки локально на устройстве пользователя.

## Онлайн-версия

Открыть приложение: <https://goviks.github.io/workspace-ultra/>.

Публикация автоматически запускается GitHub Actions после каждого push в ветку `main`.

## Возможности

- Колонки и карточки: создание, переименование, редактирование и удаление.
- Перемещение карточек между колонками и сортировка с помощью мыши или клавиатуры.
- Отметки о выполнении, дата завершения и отдельный список выполненных карточек.
- Поиск по карточкам и фильтры по тегам и статусу выполнения.
- Отмена и повтор последних 50 изменений доски.
- Светлая и тёмная темы, цветовые схемы, выбор шрифта и пользовательского фона.
- Интерфейс на русском, английском и китайском языках.
- Адаптивная раскладка и поддержка уменьшения анимации по настройкам устройства.

## Требования

- Node.js 20 или новее
- npm

## Запуск локально

```bash
npm install
npm run dev
```

Vite выведет адрес локального сервера в терминал.

## Сборка

```bash
npm run build
npm run preview
```

Команда `npm run build` проверяет TypeScript и создаёт production-сборку в `dist/`.

## Хранение данных

Доска, история изменений и пользовательские настройки сохраняются в `localStorage` текущего браузера. Серверной части, учётных записей и синхронизации между устройствами нет. Очистка данных сайта в браузере удалит локально сохранённую доску и настройки.

## Технологии

- React 18 и TypeScript (strict)
- Vite
- Tailwind CSS
- Zustand с middleware `persist`
- `@dnd-kit/core` и `@dnd-kit/sortable`

## Структура проекта

```text
src/
  components/   Компоненты доски, колонок и карточек
  data/         Переводы и цветовые схемы
  store/        Состояние доски и сохранение данных
  types/        Типы приложения
  App.tsx       Корневой интерфейс и пользовательские настройки
  index.css     Глобальные стили
  main.tsx      Точка входа
```
