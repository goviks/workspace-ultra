# Политика безопасности

## Поддерживаемые версии

Проверки безопасности выполняются для текущей версии проекта в основной ветке. Для более ранних версий исправления могут не выпускаться.

## Сообщение об уязвимости

Пожалуйста, не публикуйте детали потенциальной уязвимости в открытом issue. Отправьте описание на [goviks@yandex.ru](mailto:goviks@yandex.ru) и укажите способ безопасно связаться с вами.

Приложите затронутую версию, описание влияния и шаги для воспроизведения, если это безопасно. Не включайте в сообщение реальные пароли, токены или данные других пользователей.
