# Участие в проекте

Спасибо за интерес к WorkSpace Ultra.

## Сообщение об ошибке или предложение

Перед созданием issue проверьте, не существует ли уже похожего обсуждения. Для ошибок укажите шаги воспроизведения, ожидаемое и фактическое поведение, а также браузер и операционную систему.

## Изменения кода

1. Создайте отдельную ветку для изменения.
2. Сохраняйте существующие соглашения проекта: React, TypeScript strict и текущий стиль компонентов.
3. Не добавляйте зависимости без необходимости и предварительного обсуждения.
4. Перед отправкой изменений выполните:

   ```bash
   npm run build
   ```

5. Откройте pull request с кратким описанием проблемы и решения. Укажите, как изменение проверялось, и добавьте снимки экрана для заметных изменений интерфейса.

## Область проекта

Приложение является клиентской Kanban-доской. Изменения не должны предполагать наличие сервера, авторизации или облачной синхронизации, если это отдельно не согласовано.
